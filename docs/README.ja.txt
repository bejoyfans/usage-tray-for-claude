Claude 使用量トレイ - 説明書（日本語）
======================================
claude.ai（Pro / Max）の使用量と残りをいつでも表示し、上限に近づくと通知する
Windows 11 のタスクトレイ常駐プログラムです。

かんたんスタート
----------------
1. ZIP を好きな場所に展開します。
2. START_HERE_Install.bat をダブルクリック（言語は自動で選ばれます）。
   「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押します。
3. 小さなウィンドウが表示され、タスクトレイ（右下。^ の中に隠れている場合は
   ドラッグして出しておくと常駐します）にアイコンが追加されます。
4. 最初に一度だけブラウザ拡張機能を入れます。インストーラーが既定のブラウザを検出して
   拡張機能ページを開き、フォルダーのパスをクリップボードにコピーします。
   黒い画面に表示される 3 つの手順に従ってください（下の「ブラウザ別」参照）。
5. そのブラウザで claude.ai にログインすると、1 分以内に数値が表示されます。

しくみ
------
claude.ai には公開の使用量 API がありません。拡張機能は「設定 > 使用状況」ページに
表示された数値だけを読み取り（パスワードや Cookie には触れません）、このパソコン内
(http://127.0.0.1:47821) にのみ送ります。動くのは「あなた自身が」そのページを開いている
ときだけで、勝手にページを開いたり、クリックしたり、claude.ai に自動アクセスしたりしません。
「設定 > 使用状況」を開くたびに数値が更新されます。近道: ウィンドウの「使用量ページを開いて
更新」ボタン、トレイメニュー > 今すぐ更新、または拡張機能のツールバーボタン。
データはすべてお使いのパソコン内にあります。

ブラウザ別
----------
Chrome  : chrome://extensions →右上の「デベロッパー モード」をオン→
          「パッケージ化されていない拡張機能を読み込む」→パスを貼り付け (Ctrl+V)→フォルダーを選択。
Edge    : edge://extensions →左側の「開発者モード」をオン→「展開して読み込み」→パスを貼り付け→フォルダーを選択。
Opera   : opera://extensions →「デベロッパーモード」→「展開して読み込み」→パスを貼り付け。
Brave   : brave://extensions →「デベロッパー モード」→「パッケージ化されていない拡張機能を読み込む」→パスを貼り付け。
Vivaldi : vivaldi://extensions →「デベロッパーモード」→「パッケージ化されていない拡張機能を読み込む」→パスを貼り付け。
その他の Chromium 系ブラウザも同様です。
フォルダーの場所: %LOCALAPPDATA%\ClaudeUsageTray\extension
その後は削除・移動しないでください。起動時に「デベロッパー モードの拡張機能を無効にする」
という通知が出たら閉じてかまいません。

FIREFOX
-------
Firefox は Mozilla の署名がある拡張機能しか永続的に保持できないため、3 つの方法があります。
既定のブラウザが Firefox の場合、インストーラーがどれにするか尋ねます。
 1) 一時インストール（アカウント不要・10 秒）: about:debugging#/runtime/this-firefox →
    「一時的なアドオンを読み込む…」→ extension-firefox\manifest.json を選択
    （パスはクリップボードにあります）。Firefox を閉じると消え、起動のたびにやり直しです。
 2) 永続インストール（無料）: addons.mozilla.org に登録→開発者ハブ→「新しいアドオンを
    投稿」→「自己配布」(On your own / unlisted) → claude-usage-bridge-firefox.xpi を
    アップロード。数分で署名されるので、署名済み .xpi を Firefox にドラッグします。
 3) Firefox Developer Edition / Nightly / ESR: about:config で
    xpinstall.signatures.required を false にし、about:addons > 歯車 >
    「ファイルからアドオンをインストール…」で .xpi を選びます。通常版 Firefox では不可です。
いちばん簡単な代替案: Firefox はそのまま使い、Chrome か Edge にも拡張機能を 1 回入れます
（どれか 1 つのブラウザに入っていれば動きます）。

使い方
------
* トレイアイコンを左クリック: 小ウィンドウの表示 / 非表示。
* 右クリック: 今すぐ更新、表示モード、言語、Windows 起動時に開始、ヘルプ、アンインストール、終了。
* 表示モード「自動」はブラウザの claude.ai と Claude Code のどちらを使っているかで切り替わり、
  「固定」は常に claude.ai を表示します。
* セッションまたは週間の上限が 80%・90%・95% に達すると通知します。
* トレイアイコンは使用率を表示し、増えるほど赤くなります。

言語
----
言語は Windows の設定に合わせて自動で選ばれ、トレイメニュー > 言語で変更できます。
英語・繁体字中国語・簡体字中国語・日本語・韓国語を同梱しています。言語を追加するには
lang\en.json、lang\en.cmd、docs\README.en.txt を fr.json / fr.cmd / README.fr.txt のように
コピーして翻訳し、再起動します。メニューに自動で追加されます。
インストーラーの言語を指定: START_HERE_Install.bat ja

設定
----
ファイル: %USERPROFILE%\.claude_usage_tray\config.json（初回起動後に作成）
  thresholds    通知のしきい値。既定 [80, 90, 95]
  stale_minutes  この分数を過ぎると更新を促します。既定 60
  language      "auto" または "ja" などのコード
  browsers / code_apps  利用中のアプリを判定するプロセス名

アンインストール
----------------
次のどれでも可: トレイメニュー >「アンインストール…」/ UNINSTALL.bat をダブルクリック /
%LOCALAPPDATA%\ClaudeUsageTray\uninstall.bat を実行。プログラムを停止し、自動起動と
すべてのファイルを削除し、ブラウザの拡張機能ページを開くので「Claude Usage Bridge」を
削除してください。（Python とパッケージはそのままです。必要なら Windows の設定 > アプリから削除。）

アップデート
------------
新しい版を展開し、もう一度 START_HERE_Install.bat を実行します。拡張機能が更新された場合は
ブラウザの拡張機能ページで再読み込みしてください。

困ったときは
------------
* Chrome / Edge 142 以降で数値が出ない、または「ローカル ネットワーク」へのアクセスを
  求められる場合: 拡張機能ページ → Claude Usage Bridge →「詳細」→「サイトの設定」→
  「ローカル ネットワーク アクセス」を「許可」に。（通信先はこのパソコン自身だけです。）
* 「データなし」のまま: 拡張機能が有効か、そのブラウザで claude.ai にログイン済みか確認し、
  そのブラウザで「設定 > 使用状況」を開いてください。
* ウィンドウが出ない: トレイの ^ の中を確認。
* Python が見つからない: python.org からインストール（Add python.exe to PATH にチェック）し、再実行。
* claude.ai のデザイン変更後に数値がおかしい: ページ解析の更新が必要な場合があります。

注意
----
非公式ツールで Anthropic とは無関係です。表示される割合は claude.ai のページと同じ値で、
Anthropic は具体的なメッセージ数を公開していません。
